# CTN 数据与分析系统实施计划

目标：完整实现第三岗的数据采集、SQLite 历史存储、官方积分对账、分析及本地看板。比赛平台仅执行公开 GET；不创建账号、不发送平台互动、不读取别队私有数据。

## 阶段与交付

1. 规则审计：固定来源、版本、时间、公开数据限制及计分口径。
2. 数据底座：迁移、原始响应、版本、快照、归属证据、采集状态、日志及在线备份。
3. 采集：Latest/Trending 分页、互动与公开账号、新闻；限流、超时、有限重试、断点及排他运行。
4. 积分：幂等 CSV 导入、保留原文、保守解析、官方总分快照、差额与未知项目；独立情景计算器。
5. 分析：按时间和账号汇总、相同观察窗口、增长、相关性、词频、回复/转发关系、采样缺失与导出。
6. 本地服务与看板：概览、帖子、账号、新闻、积分、分析、运行状态及规则；筛选、详情、导出、导入与采集控制。
7. 集成验收：单元/集成/真实只读采集、界面检查、备份恢复和运行说明。

## 子 agent 分工

- 数据采集：只读传输、入库、分页/断点/限流及测试。
- 积分与分析：CSV、规则、情景计算、对账、分析及测试。
- 看板：本地 HTML/CSS/JS，依照 API 合同完成全部页面与错误/空状态。
- 主 agent：SQLite 模型、API/CLI、集成、只读联调、质量审查与最终报告。

每阶段记录修改、验证及限制，见 IMPLEMENTATION_REPORT.md。未明确的接口能力保留为未知，不通过猜测补全。
