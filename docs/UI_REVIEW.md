# 二次检查与 UI 优化

日期：2026-10-19。范围：原实现复查、界面精简、交互修复；验收读取现有本地数据。

## 问题与修复

| 问题 | 修改 |
| --- | --- |
| 分析分区直达链接、刷新后被识别为概览；跳转内容链接也可能切页 | 支持分区路由恢复，自动展开目标明细；保留当前页的跳转内容行为 |
| 快速切换帖子，较早的响应或错误可能覆盖当前详情 | 增加请求序号及弹窗状态检查；过期响应直接忽略 |
| CLI采集运行时，看板只检查自身线程，可能显示空闲 | 查询共享采集锁；忙碌时返回409及明确提示；启动前校验配置 |
| 通用表格截断行后不一定有完整记录入口 | 截断时提供完整结果折叠入口 |
| 导出按钮没有说明导出范围 | 全表导出明确标为“导出全表 CSV” |
| 图表输入顺序可能不一致 | 有效时间记录按时间排序后绘图 |
| 本队账号表单前端允许ID为0 | 前端同步正整数校验 |

## UI 调整

- 去除英文装饰页眉、导航编号和重复页面说明；收紧页头及卡片间距。
- 全局说明合并为“数据口径”；采集只读状态、更新时间保留在一行。
- 概览显示四项指标、趋势、最近采集、积分核对与覆盖率；原始运行JSON移至详情，预算停止显示简短原因。
- 积分页合并重复对账说明，批次、总分快照明细和对账依据按需展开。
- 分析页默认显示窗口、汇总单位、时区；其他条件移到高级筛选。账号分组、关系、质量及口径按需展开，分区导航可直接打开对应内容。
- 日志保留七个常用字段、固定表头和有限滚动高度；完整字段、断点和配置保留在折叠区。
- 规则明细折叠；情景计算缺少条件仍默认展开，错误不会被通用说明折叠。
- 新闻明确“剧情发布”日期，保留全文是否归档的状态。
