# CTN 问题检查与性能优化（2026-10-21）

## 已修复的问题

| 问题 | 修复 | 验证重点 |
| --- | --- | --- |
| 异步 HTTP 中间件直接进行同步会话查询，锁等待可能阻塞事件循环 | 登录校验与 Cookie 复核放入工作线程；无续期状态时跳过复核 | 慢会话查询期间健康请求仍能完成；退出/重登撤销行为保留 |
| 单个 Agent 详情为全部角色组装记忆、关系、反馈和长期统计，且重复读取完整业务状态 | 提前限定角色，复用一次状态快照和额度展示 | 完整状态读取 3→1 次，视图只生成目标角色 |
| Agent 日志仅验证角色身份也加载草稿和记忆 | 使用轻量运行状态读取 | 无关业务 JSON 无法解析时仍能读取日志，未知角色仍返回错误 |
| 调度游标、冷却与租约释放也读取完整约 15MB 业务 JSON，占用写锁超过心跳的 2 秒等待时间 | 使用既有轻量额度/运行状态事务，维护门禁只读最新额度状态 | 共用原写锁，普通事务仍保留 15 秒等待；不读取草稿/记忆，不误删替代任务租约 |
| 账号列表在分页前计算所有账号帖子数 | 先按稳定次序分页，再统计当页账号 | 分页、搜索、队伍归属、帖子计数一致 |
| 分析日期条件未利用已有规范化时间索引，且 SQLite 的日期函数丢失微秒边界 | 使用规范化时间索引过滤和排序；快照先限定帖子范围 | 微秒/时区边界正确，单边和双边日期条件采用索引；缓存版本提升为 2 |
| CSV 每行一次 ASGI 工作线程切换 | 按约 64K 字符聚合行后发送 | BOM、CSV 引号/换行/Unicode、公式保护和全部导出字节不变；缓冲不随全表增长 |
| AI Hook 空闲及结束后仍每秒更新状态 | 仅任务进行中启用计时器 | 空闲页停止周期渲染，完成耗时保持稳定 |
| 每个表格单元格重复创建 Intl 格式器 | 复用数字与悉尼时间格式器 | 输出、空值、无效时间和夏令时语义保持一致 |
| 折叠的字段详情提前序列化全部 JSON | 展开后才序列化并缓存当前内容 | 展开/收起/数据更新正确 |
| 长文证据片段已达到最高匹配分仍遍历全文并反复估算 token | 首个可容纳的最高匹配片段立即返回 | 40 项回归及 200 组与旧函数比较，选择内容、预算、偏移完全一致 |
| 已带内容指纹的前端资源统一禁止缓存 | 成功的指纹静态资源使用长期缓存 | API、页面入口、未指纹资源、缺失资源继续 no-store |

## 隔离合成基准

下表为本机隔离 SQLite/前端合成实验，不代表生产 PostgreSQL 的整体响应时间。

| 场景 | 修复前中位耗时 | 修复后中位耗时 | 比值 |
| --- | ---: | ---: | ---: |
| 账号分页（1,000 账号、50,000 帖子、5 行页面） | 37.35 ms | 18.17 ms | 2.06 倍 |
| 日期范围分析（50,000 帖子、50,000 快照） | 239.35 ms | 98.69 ms | 2.43 倍 |
| Agent 详情（10 角色、500 草稿、每角色 30 资料） | 714.695 ms | 196.753 ms | 3.63 倍 |
| CSV ASGI 导出（4,000 行，3 轮） | 2.0481 s | 0.1502 s | 13.63 倍 |

CSV 传输块数从 4,002 降至 15，SHA-256 一致。64K 阈值按字符计算，UTF-8 编码后的块大小还取决于字符与单行长度，不是严格的 64KiB 字节上限。

长文片段选择的独立局部基准（4 来源×600 段）为 2024.9→7.35 ms，每来源 token 估算 600→1 次；该 275 倍比值仅适用于这一局部函数，不代表整个 AI 请求速度。证据见 `reports/generated/system-context-performance-20261021.json`。

针对实际争锁问题另建随机 PostgreSQL 临时库，以约 15.1MB 草稿、2MB 记忆、950KB 额度状态作 5 轮交替比较：冷却事务读取量 18,077,691→950,084 字节（减少 94.7%），持锁中位时间 521.776→60.284 ms（减少 88.4%），总耗时 563.030→101.126 ms；维护门禁 279.266→48.740 ms。共享锁、其他状态保持、损坏的无关 JSON 跳过和替代租约保护均通过，临时库已删除。证据见 `reports/generated/agent-bookkeeping-postgres-20261021.json`。

证据位于 `reports/generated/system-analytics-performance-20261021.json`、`agent-read-performance-20261021.json`、`system-optimization-export-benchmark.json`。复验脚本随报告保留。
