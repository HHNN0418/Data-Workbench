# FastAPI / React 迁移报告

日期：2026-10-19。范围：更换后端 HTTP 层、重建前端与视觉体系，保留 SQLite 数据和计分/分析逻辑。

## 1. 数据保护

- 迁移前通过 SQLite 在线备份生成 `data/backups/ctn-20261019T084048855405Z.sqlite3`。
- 数据结构保持 v2；没有清空数据库、导入演示数据或执行新的平台采集。
- 保留已有 79 篇帖子、20 份互动快照、20 个账号资料、61 条新闻（2 篇全文）、5 条官方活动及 1 份总分快照。

## 2. 后端

- `server.py` 更换为 FastAPI + Uvicorn，监听 `127.0.0.1`。
- `api_models.py` 用 Pydantic 校验采集参数、CSV、积分快照和账号登记。
- 保留本机 Host 校验、同源及本地令牌、10 MiB 上限、CSV 公式防护和备份下载路径校验。
- 保留全部查询、分析、导入、导出、备份及只读采集端点；业务模块继续复用。
- 提供 `/openapi.json` 和不依赖外部 CDN 的 `/docs` 接口参考。

## 3. 前端

- React 19 + TypeScript + Vite 8；Ant Design 6、React Router、TanStack Query、ECharts。
- 页面拆分到 `frontend/src/pages/`；公共 API 层、展示组件、图表、中文标签独立。
- 查询支持缓存、取消请求和错误重试；帖子详情按 ID 隔离，旧响应不会覆盖新详情。
- 页面和图表分包加载。总览不再预加载 ECharts。
- 帖子、账号、新闻、积分流水和分析筛选使用 URL 参数；帖子详情可直接分享本机路径。
- 八个功能模块完整保留。旧 `web/` 页面和对应旧 UI 测试已退役。

## 4. 新设计

- 撤掉深色侧栏，改为顶部导航、暖白底色、细边框和单一绿色操作色。
- 总览突出采集规模、官方总分、最近帖子和数据覆盖。
- 列表统一表格与筛选；帖子/新闻详情使用抽屉；表单用独立弹层。
- 规则、原始字段和分析口径默认折叠；去掉重复说明与宣传性标题。
- 未知数据显示“—”；官方快照、公开观测、假设得分保持独立。
- 移动端使用换行工具栏、横向导航、双列指标与可横滚表格。

## 5. 安装与运行

- 新增 `Setup-CTN.ps1`，安装锁定依赖并构建；`-BuildOnly` 只处理前端。
- 更新 `Start-CTN.ps1`，启动前检查依赖和构建产物。
- Python 锁定版本见 `requirements.lock.txt`，前端见 `frontend/pnpm-lock.yaml`。
- 本工作区已安装依赖并构建，直接运行 `./Start-CTN.ps1`。
