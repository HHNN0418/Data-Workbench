# 内容研究试用接入

2026-10-20。试用入口沿用现有分析和 Agent 页面。

## 使用

1. 打开“分析 → AI 分析 → 内容研究”，选择已配置的文字 AI 服务。资料范围沿用分析页的账号、作者和发布时间筛选。
2. 可选填写“本次输出上限”（256–8192 tokens）；留空沿用连接配置。此项只影响此次研究，不修改全局模型或角色设置。点击“开始研究并保存”，后端使用本地已采集帖子、普通对照和新闻资料调用所选服务，保存原始报告及出处。生成新报告不会自动替换当前参考。
3. 核对报告与来源后，点击“供发文 Agent 参考”。后续正常发文决策会获得这份报告的有界片段，角色可以自行调整或忽略。报告默认两小时到期，也可以手动停用。
4. 在“角色完整管理 → 总览 → 研究参考与提供记录”查看实际提供记录。它证明报告被放入该次模型请求，不证明角色采纳建议或已经发布。
5. 在“Agent → 额度管理 → 发文竞赛与资源”使用竞赛开关和模型奖励设置。竞赛默认关闭，开关不启动角色；小时结算、竞技份额、新人保护和模型奖励见 [发文竞赛说明](AGENT_COMPETITION_IMPLEMENTATION.md)。

直接入口：`/analysis?analysis_tab=ai&ai_view=research` 和 `/agents?tab=quotas`。不新增主导航。原有热门文章分析、文章生成、举报线索和资料聊天继续使用原入口。

## 数据与执行

读取页面只查询本地数据。研究由明确的手动操作触发，复用现有 AI 服务与并发控制。推理模型可能在较低输出预算下耗尽额度而无法完成最终回答，此时返回错误且不保存半截报告；可以调整本次输出预算后重新研究。没有定时调用、后台自动研究或自动开启角色。

报告、当前参考和最近提供记录保存在已有 `checkpoints` 的 `agent_content_research_v1` 键，随现有数据库备份保存。试用保留最近十份报告并保留当前选中版本；提供记录每角色最多三十条、全队最多三百条。这是有限历史，不能当作完整采用审计。

激活使用配置版本校验。过期、引用编号非法或已知来源不可用的报告不供后续决策参考；历史仍可查看。只校验引用编号属于送入模型的资料，不保证每句话得到来源支持。

研究参考与人设、实际经历、操作权限分别处理。报告不能添加动作目标、提高额度或代替原帖事实。未启用参考时，原有角色提示和决策协议沿用原流程。

接口：`GET /api/ai/research`、`POST /api/ai/research/run`、`POST /api/ai/research/active`。写接口沿用成员登录和 CSRF 校验。模型密钥不进入研究状态、响应或参考上下文。

完整竞赛设计见 [内容研究与 Agent 关注度竞赛设计](AGENT_COMPETITION_DESIGN.md)，已实现的开关、规则与入口见 [发文竞赛说明](AGENT_COMPETITION_IMPLEMENTATION.md)。
