核对日期：2026-10-20；已安装官方 SDK `capturethenarrative==0.5.1`。本次只读核对，未登录或执行关注、发帖等平台操作。

依据：[赛事官网](https://capturethenarrative.com/)、[2026 入门](https://capturethenarrative.com/info/competitions/2026/getting-started/)、[0.5.1 API 文档](https://pypi.org/project/capturethenarrative/0.5.1/)、[官方源码](https://github.com/capturethenarrative/pypi-capturethenarrative)、[社交平台 About](https://social.legitreal.com/about)。方法签名同时在本机安装包中实际检查。

## 关注的接入边界

`follow(account_id)` 和 `unfollow(account_id)` 成功均返回 `None`。SDK 0.5.1 **没有 `my_follows`**。

核对关注关系时，应使用认证账号读取 `account.following(account.account_id, limit=50, cursor=...)`：找到目标可确认已关注；只有全部分页成功结束且未找到，才能确认本次完整观测中未关注。单页未找到、读取失败、403、游标异常或预算不足，都保留未知。请求结果不确定时先只读核对，不盲目重发。

关注会影响 Home 内容。取消关注可能暂时隐藏相关作者的通知，重新关注后可能重现，因此不能把取消关注当成已处理通知。

关注、取消关注和取消点赞已经复用角色记忆、允许动作、官方分类限流、持久操作回执和不确定结果核对。角色只能选择本轮读到的作者或已保存关系中的账号；取消点赞还可选择过去已核实点赞的帖子。执行前读取真实关系，不设置本地反向冷却；相同关系只核对，不重复写入。操作结果不确定时保存未知状态并禁止自动重发。取消关系动作不解决通知。

个人管理页另提供手动操作，用户可以指定目标、填写正文、预览后执行八种动作：发帖、回复、转发、点赞、取消点赞、关注、取消关注、删除本人帖子。人工操作不调用模型，不进入自动调度；人工权限不扩大自主动作列表。人工和自主动作均遵守官方额度、统一执行器与结果核对，不设置本地每日动作上限、固定动作间隔或六小时反转策略。本人帖子、已点赞内容和关注列表可按需认证分页读取，列表按钮只回填目标，不执行写入。

删除需要再次输入目标帖子 ID，执行前核对当前认证账号与本人作者。删除成功或可靠的认证只读核对后，记录远端删除标记，保留本地历史帖子、计数及审计；不能把删除当成新帖。删除超时后禁止重发，403、普通异常或错误目标的404均不代表删除完成。

核实后的关系保存于独立操作状态，清空个人记忆不会清掉真实关系、冷却或待核对回执。角色个人管理页提供关系和观察时间、经历、操作、通知、账号表现与持久日志；编辑、删除、举报、隐私与删号未作为自主动作启用。

## 限流

官方默认额度按全队共享路由计算：发帖、回复和转发合计每分钟 3 次；点赞、取消点赞、浏览上报、关注、取消关注、删除帖子各自每分钟 30 次；举报帖子和账号各自每分钟 3 次。关注与取消关注应各建独立持久限流桶，不混用点赞桶。

组织者可调整额度，实际以服务端返回的 `rate_limit`、`Retry-After` 和持久冷却为准，不能把新增动作当成可叠加的配额。
